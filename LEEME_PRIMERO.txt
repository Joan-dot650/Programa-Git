1. Haz clic derecho sobre el ZIP y selecciona "Extraer todo".
2. Abre la carpeta extraída y después entra en raizvolt-web.
3. Necesitas Java JDK 17 o superior. Compruébalo en CMD con: java -version
4. Haz doble clic en ejecutar.bat y deja la ventana abierta.
5. Cuando aparezca "RAÍZVOLT ESTÁ LISTO", abre en el navegador:
   http://localhost:8080/raizvolt/productos
6. Pulsa "Nuevo producto" para registrar tu primer producto de prueba.
7. Para detener la aplicación, vuelve a la ventana negra y presiona Ctrl+C.

LEE Guia_RaizVolt_Web.pdf para seguir el procedimiento explicado.
El catálogo comienza vacío. La base se crea automáticamente en raizvolt-web/datos.
No borres esa carpeta si quieres conservar tus registros.

NO abras index.jsp con doble clic ni con Live Server: JSP necesita el servidor Java.
Para esta opción no necesitas instalar XAMPP ni un Tomcat aparte: va incluido.

Si aparece "puerto ocupado", abre CMD dentro de raizvolt-web y escribe:
  ejecutar.bat 8081
Después abre http://localhost:8081/raizvolt/productos

PARA EDITAR Y VOLVER A COMPILAR:
Abre la carpeta raizvolt-web en Visual Studio Code. Después ejecuta compilar.bat.
Para comprobar el proyecto: primero compilar.bat y luego pruebas.bat.
Para usar Linux/macOS: bash ejecutar.sh (también compilar.sh y pruebas.sh).
