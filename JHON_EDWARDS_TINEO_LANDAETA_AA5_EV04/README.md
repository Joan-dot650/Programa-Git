## Ejecutar

1. Extrae todo el ZIP e instala Node.js 24.x y Postman.
2. Abre `PREPARAR_POSTMAN_WINDOWS.bat` y después `INICIAR_API_WINDOWS.bat`.
3. Importa `postman/RaizVolt_AA5_EV04.postman_collection.json` y `postman/entorno.local.json` en Postman.
4. Selecciona el entorno y ejecuta la colección completa en orden.
