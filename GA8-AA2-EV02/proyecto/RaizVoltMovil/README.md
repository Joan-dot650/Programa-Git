# Proyecto Android RaízVolt Móvil

Abrir esta carpeta en Android Studio. Instrucciones completas en [README de la entrega](../../README.md).

Configuración: Java 17, SDK 35, AGP 8.9.2, Gradle 8.11.1. API mínima 23.

Windows PowerShell: `.\gradlew.bat testDebugUnitTest assembleDebug assembleDebugAndroidTest lintDebug`

Linux/macOS: sustituir `.\gradlew.bat` por `./gradlew`.
